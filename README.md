                              simpeg
                              =========

Simple Employee Management Applications

Just simple employee management application with CodeIgniter, now with a modern **AdminLTE 4** (Bootstrap 5.3) user interface.

Modernisasi UI
==============

Seluruh tampilan telah dimigrasikan dari Twitter Bootstrap 2 ke AdminLTE 4 terbaru:

* Layout AdminLTE 4 dengan sidebar treeview, breadcrumb, dan dark-mode support
* Komponen layout terpusat di `application/views/dashboard_admin/layout/` (`main_header`, `main_footer`, `iframe_header`, `iframe_footer`)
* Halaman login, dashboard, master data, laporan, dan detail pegawai didesain ulang
* Form input/edit dalam popup iframe (Colorbox + jQuery)
* Datepicker menggunakan Flatpickr (locale Indonesia)
* Aset AdminLTE 4 dibundel lokal di `asset/adminlte/`, ikon Bootstrap Icons via CDN
